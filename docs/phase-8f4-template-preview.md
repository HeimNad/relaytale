# Phase 8F.4 · 本地模板预览与语言版本

2026-10-08。本阶段复用 8F.3 的固定目录和有界渲染，不增加 HTTP 路由、数据库迁移或出站行为。

## 本地源码预览

```sh
go run ./examples/template-preview -template order-template-versioned.json < variables.json > preview.json
```

variables.json 为原模板声明的字符串对象，例如 `{"number":"ORDER-42"}`。输出 JSON 包含 dry_run=true、ID、版本、语言、主题、文本和 HTML 源码。工具不会入队、创建存档、占用投递配额、发送邮件、访问网址或打开浏览器；HTML 作为 JSON 字符串转义，不当网页运行。预览结果可能含业务隐私，应作为本地私人文件保管，不提交 Git。

输入模板最多 32 KiB，变量文件最多 16 KiB；继续沿用 8F.3 的单变量/总变量和渲染输出限制、重复/未知字段拒绝、HTML 上下文转义及主题注入校验。带版本模板必须匹配摘要；没有版本的草稿会计算版本，允许发布前检查，但预览不代表已发布。源模板可包含管理员提供的静态 HTML，输出不承诺病毒扫描或净化。

这是主题/正文源码预览，不是邮件客户端视觉预览，也不构建完整 EML 或验证信封、附件、Provider、到期和投递配额。完整消息仍通过既有沙箱提交与 MIME inspection 验证；生产投递需独立授权。

## 显式语言版本

管理员的 SendTemplate 可增加 language，例如 `en`、`zh-cn`、`pt-br`。标签必须小写，总长最多 35 字节，每段 1–8 字符，首段只含 a–z，后续段可含 a–z/0–9，以单个连字符分隔；这是受限标签形式，不实现完整语言标准、识别或回退。大写、下划线、空段及控制字符拒绝。

同 ID 的语言正文应作为独立配置对象发布，各自计算内容版本，计入每身份最多八个版本的既有上限。声明 language 后，摘要使用 `relaytale.template.v2` 加零字节命名空间，在原 ID/Subject/Text/HTML 字段后加入 language，再加入排序后的变量名，所有字段仍使用八字节大端 UTF-8 长度前缀。直接修改旧模板的 language 而保留旧摘要会使启动验证失败；请用 template-version 工具计算新版本。

网站请求 template 中必须同时选择匹配的 ID、version 和 language：

```json
{
  "date": "2026-10-08T12:00:00Z",
  "template": {
    "id": "order",
    "version": "替换为对应语言模板生成的64字符摘要",
    "language": "zh-cn",
    "variables": {"number":"ORDER-42"}
  }
}
```

不自动从 zh-cn 回退 zh/en，也不根据请求头或收件地址猜语言。不匹配统一返回 400 invalid_json_message；同幂等键选择另一个有效语言版本会产生 409 冲突。版本、语言和变量参与构建指纹。

有语言标签的模板使用 json-v4 并写入 Content-Language。省略或显式空 language 仅选择无标签模板；无标签版本继续使用原摘要命名空间和 json-v3，JSON v1/v2/v3 的既有字节保持。语言只描述正文，不声明收件人语言或送达状态。

启动审计模板目录追加语言字段，不记录正文或变量。现有队列重试继续读原存档，不重新选择语言或访问模板目录。
