# Phase 9C.4 · 工作台统计与跨项目逻辑容量

## 实现范围

工作台增加“统计与容量”。管理读取权限下，按稳定网站 API 身份、来源和生产/测试环境分组，显示提交窗口内邮件的当前状态、原文状态及逻辑字节。SMTP 和 internal 来源分别合计，不展示账号地址、邮件主题、邮件 ID、磁盘路径或凭证。网站身份不是网站域名，也不等于凭证名称；历史身份即使停用也仍参与统计。

管理入口：`GET /admin/v1/statistics?from=RFC3339&until=RFC3339`；浏览器通过既有 `/console/api/statistics` 会话桥接读取。viewer、operator 和 admin 均可读取；网站发信凭证不能读取管理汇总。原 `/v1/statistics` 的身份隔离保持不变。

## 范围与容量边界

- from 包含，until 不包含，UTC 微秒精度，最多连续 31×24 小时，until 不得晚于数据库快照。查询参数、消息体与编码规则复用 9C.3 的封闭校验。
- 数据库 Repeatable Read 只读事务；沿用管理接口 8 个并发槽与 5 秒超时。读取全来源的 created_at 时间索引，最多取 10001 行；超过 10000 封或 256 个分组返回 422，不返回部分汇总。失败、取消或超时不返回部分结果。
- 响应 schema_version=1，snapshot_at/from/until/message_count/groups；每组 source/api_key_id（仅 API）/environment/message_count/messages_by_status/archives_by_state/logical_raw_bytes_by_archive_state。空窗口 groups=[]，计数为零；分组按来源、环境、身份稳定排序。整数溢出或异常大小拒绝返回。
- 窗口代表邮件提交批次，展示查询时状态；不是窗口内投递事件数量、逐收件人成功率或入箱率。SMTP_ACCEPTED 只代表 SMTP 接受。
- AVAILABLE、PURGE_PENDING、PURGED 分开展示记录大小。PURGED 的大小是历史原文大小，不能据此推断磁盘仍占用；PURGE_PENDING 也不能推断文件还在。文件系统孤儿、临时文件、日志、数据库索引/WAL、备份和对象存储费用不在此次统计内。整个实例全部历史记录的物理容量盘点仍待后续实施。

## 页面行为

沿用工作台既有蓝色、白底与系统中文字体。布局为“时间范围与刷新 → 统计口径 → 时间/快照 → 分组表格”，不另加装饰性图表或虚构成功率。表格使用现有移动端逐行标签、键盘焦点和文字状态标记。主题和状态值通过 textContent 构建，不拼接 HTML。

可选最近 1 小时、1 天、7 天、31 天；刷新重新计算窗口，不自动轮询。结束时间使用浏览器时间减一分钟并在页面明确说明，减少最近写入及轻微时钟差异的影响；明显时钟偏差仍由服务端拒绝，页面提示核对本机时间。422 时可缩短为一小时；更繁忙的部署可通过管理 API 指定更短窗口。超过 JavaScript 安全整数范围的字节显示“约”，精确值应使用能解析 int64 的 API 客户端。

路由切换、退出登录后，旧请求不会把结果写入新页面。读取不新增尝试、不变更邮件、不触发回调或清理、不打开 EML。浏览器操作沿用原有会话、来源验证与 CSRF 边界。

## 验收

- 完整 `make ci` 通过：gofmt、go vet、构建及全部竞争检测；集成测试 233.589 秒。
- 最后新增边界回归：`TestManagementStatistics*` 竞争检测通过，4.205 秒；覆盖多网站、生产/测试/SMTP、三个读取角色、网站凭证拒绝、未经认证/来源拒绝、HEAD、未来/异常参数、零结果、10000/10001 封、256/257 分组、字节溢出，以及无维护写入/投递尝试。
- 最终 UI 的 JavaScript 语法与 Prettier 检查通过。
- 本机 Chrome + 实际工作台会话/隔离服务完成 4 个 Playwright 用例，10.1 秒；覆盖真实多来源结果、viewer、范围切换、390px 窄屏、422 缩小范围、空结果、既有会话过期与写权限边界。错误/空结果的浏览器分支使用拦截响应，服务端边界另有数据库集成验收。桌面与手机截图人工核对。
- 本阶段未新增数据库迁移，也未访问真实 Provider、DNS、收件箱或实际发送邮件。

首次新用例曾误用不存在的 attempts 表名；已改为 delivery_attempts，最终完整与边界测试均通过。模拟批量邮件使用独立唯一路径，不创建文件。截图与测试产物只在本地保留，不提交。
