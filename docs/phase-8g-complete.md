# Phase 8G：定时、受控取消、原子替换与改期

日期：2026-10-11。本类别建立在 [8G.1 定时准入](phase-8g1-scheduled-submission.md) 上，完成网站侧定时、取消、替换待发通知及改期的安全闭环。代码不连接真实 Provider，验收使用隔离 PostgreSQL 与 Fake SMTP。

## 已完成的能力与边界

- 定时：保留不可改写的最早发送时间、最多 720 小时排期、每网站 100 封 / 128 MiB 未来任务容量；到点前不能领取或授权 DATA。
- 取消：`POST /v1/messages/{id}/cancel`，服务器凭证、空请求体。同网站生产任务才可操作；成功返回 `message_id`、`status: CANCELLED`、`replayed`。重试同一个操作不增加事件。
- 替换：在原有 `POST /v1/messages` 中增加单个 `X-RelayTale-Replaces: <旧 Gateway ID>`。使用新的 Idempotency-Key；取消旧邮件、预留新配额、发布原文、接纳新邮件和记录关系在同一事务内完成。
- 改期：以替换提交新的 `X-RelayTale-Schedule-At`，不原地修改旧排期。新邮件获得自己的 Gateway ID、原文与幂等键；如果使用 JSON 构建，必须保留该新请求的确定性 Date 和完整参数用于重放。
- 查询和通知：状态事件与已配置签名 Webhook 支持 `MESSAGE_CANCELLED`；新邮件状态响应的 `X-RelayTale-Replaces` 标明旧 ID。管理读取提供取消时间和替换关系。

取消范围比“尚未发出 DATA”更严格：只接受没有活动尝试的 QUEUED / TEMP_FAILED 任务。worker 领取已提交，即使尚未授权 DATA，也返回 **409 message_not_cancellable**。任何历史 DATA 授权、可能发送、SMTP 接受或 UNKNOWN 证据都拒绝取消。活动租约过期不等于可取消，必须先完成正常恢复；未授权 DATA 的恢复任务可重新评估，已授权则保留 UNKNOWN。

这不是远端撤回。永久失败、抑制和过期收件人事实不会被覆盖，只有未来可尝试的收件人改为 CANCELLED。SMTP 来源、沙箱、别的网站或不存在的目标返回 404。网站凭证撤销和独立请求并发/速率限制继续生效。

## 事务与数据库保护

取消和替换按 website → message 顺序加锁；website 使用 NO KEY UPDATE，兼容幂等台账外键锁。message 行锁与 worker 领取、DATA 授权共用。领取先胜出则取消拒绝；取消先胜出则任务不再满足领取条件。两个替换请求最多一个胜出。

迁移 `00029_pending_control.sql` 增加不可擦除 cancelled_at、不可改写替换关系及唯一旧目标索引。约束禁止已取消任务恢复为可发送消息；新尝试/收件人插入先取得 message 锁；既有子行更新只读取取消标记，避免 recorder 先持子行锁再取 message 锁，与 Finish 形成反向锁序。触发器拒绝已取消任务恢复投递。取消事件和 Webhook outbox 与状态一起提交。新请求指纹 v6 包含精确旧 Gateway ID；未使用替换时保留 v1–v5 字节兼容。重放先返回已经提交的台账，不再次取消旧任务。

替换不返还历史接纳配额。未来排期容量则在同一事务中释放旧任务占用并检查新任务；新请求超额、存档失败或事务失败，旧取消、新配额、新台账及通知均回滚。发布后提交结果不确定时，原文保留供孤儿对账，客户端只能重试同一新请求和幂等键。

精确旧 Gateway ID 是本阶段的身份范围替换目标，不提供“搜索所有同业务标签并自动取消”的模糊替换。业务网站需保存当前目标 ID；并发更新冲突必须重新读取业务状态，不能自动再发一封。批量接纳、活动连接中断及工作台取消按钮不属于本类别范围。

## 网站接入示例

取消预约提醒：服务器请求 `POST /v1/messages/<旧 ID>/cancel`，带原网站 Bearer 凭证和空请求体。200 表示取消已提交；409 表示未取消，不能向用户显示“已撤回”。503 表示结果未知，重试相同取消并查询状态。

更新预约时间或验证码：持久保存新的幂等键和完整新请求，提交新原文 / JSON，附 `X-RelayTale-Replaces: <旧 ID>`；改期再附新的最早时间。202 表示新任务已被网关接纳，旧任务已取消；不代表新邮件已入箱。网络确认丢失后重放同一请求，读取返回的原新 ID。

## 升级与恢复

停止运行实例和辅助写入进程，执行既有显式离线迁移，再使用受限运行账号启动。没有新增表或运行权限类别。Down 明确拒绝自动降级，不能抹除取消历史。备份恢复校验新增取消状态、收件人、DATA 证据、事件和同网站替换关系一致性检查；恢复后幂等重放保持相同新 ID，启动阻断仍需显式人工解除。
