# Phase 8E.3b：沙箱工具、网站示例与接口契约

本阶段在 8E.3a 的不可变测试身份和零 SMTP 闸门上增加 MIME 结构检查、受控结果模拟、可运行网站参考后端与 OpenAPI 3.1 契约。8E.3 整体范围由两个阶段共同完成；不代表生产就绪。

## 行为与安全边界

新增 GET `/v1/messages/{id}/inspection`，只接受当前身份拥有的 sandbox 存档。读取时限制大小并验证 SHA-256、文件类型及根目录约束；损坏返回不可用、清理后返回 410。检查最大 2 MiB、64 个部件、8 层嵌套和 64 KiB 部件头；获取 32 MiB 工作内存预算。预算是工作集估算，不是进程 RSS 保证。大邮件仍可按已有提交上限存档，但不能用此小型诊断端点检查。

检查返回类型、附件名称、传输编码、编码及可确定的解码字节数。不会返回正文、渲染 HTML、访问远程资源或解压附件；内嵌 message/rfc822 保持 opaque。

新增 POST `/v1/messages/{id}/simulations`，仅允许五种独立 SANDBOX_SIMULATED_* 事件。事件、幂等账本及签名通知 outbox 在同一事务提交；同键不同参数冲突，每封邮件最多 100 次提交。数据库强制环境、关联、事件内容一致性及追加历史，并在事务结束时拒绝缺少账本的模拟事件。备份恢复增加相同校验。

模拟不改变真实消息/收件人状态，不生成 attempts，不更新 suppression、Provider 健康或额度。accepted 不冒充 SMTP_ACCEPTED，bounce 不冒充可信远端 DSN。生产身份访问工具返回 403。

## 网站闭环

[参考后端](../examples/website/README.md) 持久化请求后提交，保存稳定业务关联及 message_id；确认丢失后同键恢复。它在提交前核对沙箱环境，拒绝生产凭证。

通知使用原始字节 HMAC 验签、时间窗口和轮换密钥，事务收件箱按 event_id 去重，提交后才确认。通知只标记需要重新查询；查询与新通知竞争时采用 revision 条件更新，防止丢失刷新信号或旧快照覆盖新结果。后台定期查询重试，重启保留待处理数据。

[OpenAPI 契约](api/website.openapi.json) 描述提交、检索、查询、检查、模拟与外部通知。重复收件人/标签 Header 须按运行时要求发送，不能由生成客户端自动逗号合并；选择 schema_version=2 才返回业务关联。契约不是所有语言 SDK。

## 验收

针对性测试覆盖 MIME 边界、附件、损坏存档与路径逃逸；模拟幂等/冲突、身份隔离、通知故障事务回滚、数据库账本约束及备份恢复；网站确认丢失后重启重试、HTTP 提交/查询、签名与时间窗口、重复/乱序通知、查询竞争以及真实 outbox worker 回调。所有网站/模拟闭环断言无 SMTP 尝试。

完整 `make ci` 已通过：格式、go vet、go build、全部 go test -race（隔离 PostgreSQL 集成测试 184.286 秒）。OpenAPI JSON 可解析且 75 处内部引用均可解析；这不是独立 OpenAPI 校验器的完整规范认证。最终路径收紧后再次通过网站闭环 race 回归（2.453 秒）；暂存差异检查与离线密钥扫描通过。真实 Provider、生产 HTTPS 回调、生产权限与密钥轮换不属于本阶段验收；后续优先推进 9B 生产门槛。
