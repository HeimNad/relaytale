# 7B.8 网站接入验收

日期：2026-10-11。最终代码已完成本地隔离验收与全套浏览器验收。阶段里程碑为 `phase-7b8`；不代表生产部署或 Provider 可信来源验收完成。

## 网站如何获得退信结果

网站参考后端保持默认沙箱；生产接入须同时设置 `DEMO_ENVIRONMENT=production` 与 `DEMO_ALLOW_PRODUCTION=true`，提交前检查身份环境。新字段按环境隔离持久化记录，不能复用旧环境的幂等请求。生产使用独立网站数据库，旧沙箱记录不会被当作生产记录。

网站接收签名回调后先提交持久化通知收件箱，再异步查询 Gateway。生产对账同时读取 SMTP 状态与独立人工反馈，分别保存 `snapshot` 和 `feedback`。新增反馈 `snapshot_at`，结合通知修订号及两份快照时间阻止旧查询覆盖更新结果。超过单页容量时保留待刷新标记，不静默截断。网站契约与反馈回调字段已补入 OpenAPI。

管理员关联、确认失败、撤回及晚到证据冲突都可通知网站。来源仍为 `UNVERIFIED`，自动抑制仍关闭，SMTP_ACCEPTED 不会被改写成投递失败。Gateway 签名证明通知来自 Gateway，不能证明原始退信来自 Provider。

## 全链路证据

`TestWebsiteProductionManualFeedbackSignedReconciliation` 使用真实发信 API → 隔离 PostgreSQL / Fake SMTP → 管理 API 关联及确认/撤回 → 持久化 outbox worker → 签名 HTTP → 示例网站持久化收件箱 → 状态/反馈查询。覆盖默认沙箱阻断生产凭证、生产确认开关、旧通知重放、网站实例重建及晚到证据冲突。

新增真实浏览器测试不拦截或伪造管理 API 写入。管理员通过现有界面真实关联、确认和撤回，测试查询示例网站的 HTTP 端点，核对待核验、人工确认失败和撤回三种状态，并在每步检查 SMTP_ACCEPTED、UNVERIFIED 和自动抑制关闭。测试夹具及其只读查询代理仅由浏览器测试的显式环境开关启用，不属于产品路由。

生产 HTTPS/TLS/SSRF 检查没有放宽；只有注入的测试发送器可访问本机测试目标。没有向真实邮箱发送本阶段验收邮件。

## 发现与修复

第一轮浏览器测试在撤回后等待刷新超时。定位为夹具每收到一条回调便立即做两次状态查询，耗尽真实网站身份的读取预算；后台对账因此报告暂时不可用。

修复为批量接收回调后每两秒对账，保持 Gateway 的限速规则。测试脚本也补上夹具退出结果检查：即使界面断言通过，后台回调或对账失败仍使整次验收失败。修改后真实浏览器闭环与退出检查均通过。生产示例本来使用五秒对账周期及失败重试，仍维持该行为。

- 网站相关数据库竞态测试通过，16.317 秒；网站示例、API 和最终集成测试夹具的静态检查通过。

此前沙箱无法访问 Docker、绑定测试端口、下载依赖，自动审批也曾超时；Docker 重启后执行权限恢复，以上检查使用可运行的隔离环境。macOS 默认临时路径别名曾使恢复工具的路径安全检查拒绝测试目录，改用真实的 `/private/tmp` 后通过，没有放宽路径检查。私有 temp 文件及其旧格式没有改动，Docker 构建上下文仍排除 temp。
